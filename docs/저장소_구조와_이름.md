# 저장소 구조와 이름

## 폴더

```text
interfaces/fleet_interfaces/  msg·srv·action, contract.yaml(인터페이스 원본)
config/robots.yaml            로봇과 스테이션
pc/central/                   주문·재고·화면 백엔드          관제 PC
pc/fleet_core/                판단 로직(ROS 없음), 레인 지도   관제 PC
pc/fleet_manager/             fleet_core를 ROS에 잇는 노드     관제 PC
pinky/pinky_fsm/              이동·도킹 명령 → Nav2            핑키 Pi
pinky/pinky_dock/             정밀 도킹                        핑키 Pi
pinky/pinky_nav_config/       Nav2·AMCL 설정, 지도             핑키 Pi
arm/arm_control/              팔 동작, 작업공간·출고 서버       팔 PC
arm/arm_vision/               상품 인식                        팔 PC
sim/fake_robots/              가짜 노드, 심판, 시나리오
sim/fleet_gz_sim/             Gazebo 3대 시뮬
bringup/iponic_bringup/       pc·pinky·sim_gz launch
tools/, scripts/              전수 검사·재생·압박 시험, 계약 검사
```

`fleet_core`는 ROS를 쓰지 않는다. `pinky/*`는 `pc/*`를 import하지 않는다.

## 이름 규칙

| 대상 | 규칙 | 예 |
|---|---|---|
| 패키지 | snake_case, 앞말은 역할 | `fleet_core`, `pinky_fsm` |
| 실행 파일 | 노드 이름 + `_node` | `fleet_manager_node` |
| 로봇별 노드 | 이름은 같게, namespace로 구분 | `/pinky1/pinky_fsm` |
| 토픽·서비스·액션 | `/{주인}/{무엇}` | `/fleet/zones`, `/pinky2/move_to` |
| 로봇 ID | 소문자 + 번호 | `pinky1`, `arm3` |
| 지점·구역 ID | 데이터에만 쓰고 ROS 이름에 넣지 않음 | `P-3`, `WORK` |
| 타입 | PascalCase, 목록은 `~Array` | `ZoneStateArray` |
| 상수·이벤트 코드 | UPPER_SNAKE | `STATE_MOVING`, `GOAL_RETRY` |
| 파라미터 | snake_case + 단위 | `release_distance_m` |
| launch | `{장치}.launch.py` | `pinky.launch.py` |
| 브랜치 | `feat/` `fix/` `docs/` | `feat/pinky-fsm-path` |

## 인터페이스

원본은 `interfaces/fleet_interfaces/contract.yaml`.

| 이름 | 타입 | 방향 |
|---|---|---|
| `/central/orders` | `OrderBoard` | central → FMS |
| `/central/events` | `FleetEvent` | FMS·central → 화면 |
| `/central/submit_order`, `/central/set_run_mode` | srv `SubmitOrder`, `SetRunMode` | 화면 → central |
| `/central/report_order` | srv `ReportOrder` | FMS → central |
| `/fleet/robots`, `/fleet/assignments`, `/fleet/zones` | `RobotStatusArray`, `AssignmentArray`, `ZoneStateArray` | FMS → central |
| `/fleet/heartbeat` | `std_msgs/Header` | FMS → 핑키 |
| `/fleet/confirm_clear` | srv `ConfirmClear` | central → FMS |
| `/{pinky}/move_to`, `/{pinky}/dock` | action `MoveTo`, `Dock` | FMS → 핑키 |
| `/{pinky}/state` | `RobotState` | 핑키 → FMS |
| `/{pinky}/navigate_to_pose` | action `NavigateToPose` | 핑키 안(Nav2), 실물만 |
| `/workcell/fill_basket` | action `FillBasket` | FMS → 작업공간 |
| `/arm3/swap_basket` | action `SwapBasket` | FMS → arm3 |
| `/{arm}/state` | `ArmState` | 팔이 발행 |
| `/{arm}/vision/items` | `ItemArray` | 비전이 발행 |
